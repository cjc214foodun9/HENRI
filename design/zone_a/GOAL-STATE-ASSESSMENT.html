HENRI goal-state assessment: is AAII v4.3 SOTA realistic?

Cycle 2026-10-03. HEAD 4a0ccd8; main a039095 untouched. Ledger 1807 records. Every claim below carries its evidence class.

Verdict: not realistic as built, and not probable without a new outer layer

HENRI today is a research kernel and a memory subsystem. It is not a vision-language-action model. The repo holds no vision encoder, no language backbone in the load path, no action decoder, and no model-scale training pipeline. AAII v4.3 scores frontier multimodal reasoning models. Two empirical hypotheses are already falsified at production scale. No benchmark was run.

This is not a dismissal. The memory architecture is genuinely differentiated and is a component a VLA needs. The correct claim is: HENRI can plausibly be a novel continual-learning memory layer for a frontier-class backbone. It cannot be the backbone on current evidence.

5. The genuinely differentiated asset

Zone C is the novel part. It is a 65536-dim engram store with 2000-dim HNSW retrieval, provable round-trip fidelity, and boundary axioms that condition a step. Three properties are unusual together:

  1. Storage without VRAM residency. The corpus never loads whole. Write does .cpu(); read uses np.frombuffer on CPU. Only individual 256 KiB engrams cross to VRAM to condition a step.
  2. Full-rank reshaping at O(D) parameters. The DIAGONAL finding: rank and parameter count differ. A phase operator reshapes local geometry at ~105 params, not 109.
  3. Enforced memory contract. The 32 GiB crash is now structurally impossible: guard test, kill-proof, and a fail-closed cap in the thermostat.

6. Two honest architectures

A. HENRI AS MEMORY LAYER  (plausible, testable soon)
   frontier backbone ──> wave state ──> Zone C memory ──> conditioned step
   (Qwen3-VL etc.)                      (this repo)       (this repo)
   Missing: backbone enabled, weights fetched, transfer evidence
   Cost: eval is local; backbone inference needs 1 GPU

B. HENRI AS ITS OWN MODEL  (not supported)
   everything in A, PLUS: vision encoder, LM head, action decoder,
   instruction corpus, model-scale training, AAII harness
   Missing: all six. Evidence: none.

Path A is the only one with a short falsifiable next step. Path B is a research program, not a near-term deliverable, and should not be described as probable.
