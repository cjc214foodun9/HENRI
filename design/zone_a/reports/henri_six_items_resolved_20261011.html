4. Two of my own hypotheses falsified

Cross-fold scale hypothesis — FALSIFIED. I claimed the folds differ by filtration SCALE (2K39 disperse, cited rmsd 3.29 Å). Measured: median CA distance 15.13 Å (1D3Z) vs 15.06 Å (2K39). The medians are equal, so the difference is not a global scale effect. Recorded, not hidden.

Cross-fold ARM B — EXACT NO-OP. I "normalised" the Betti curve by the ensemble median. A Betti curve is a rank function of the filtration value, so betti(D, ε·median) and betti(D/median, ε) count the identical feature set. ARM B duplicates ARM A to printed precision. Scale normalisation is vacuous on CURVES; it only bites on the DIAGRAM, which ARM C uses.

6. Self-caught defects — 14 in this session

Naming them is a deliverable. Several were in my own tests, and one made a working statistic look broken.

  • Normalisation. Divided inner products by √D where Cauchy-Schwarz already bounds them at 1, so an exact axiom member scored −0.024 instead of ~0.95. Divide by the NORMS.
  • Wrong wave family. Fed a unit-L2-norm family (chance 1.2e-6) to a statistic whose chance constant belongs to the entry-unimodular family (0.011). Four orders of magnitude apart.
  • V_E identity check. My "contrast" reduced to one feature in costume (r = 1.0000) on an independent-phase family. The clause fired and refused the verdict — the gate working.
  • MaxMin written as a BINARY op. Symmetric in its arguments, so the contraction ratio measured 0.0 for every pair — a tautology that would have read as a perfect result. Dutta's operator is UNARY.
  • parse_models returns a 2-tuple. My filter len(m) >= 8 removed every model, and the fail-closed guard passed on two empty lists. Root cause of a 0-model fetch.
  • torch.median on an even count returns the lower middle, so a two-valued fixture pins at 0.0 — genuinely saturated, not in-band. My expected value was wrong.
  • t vs t² assumed near-collinear — measured r = 0.9668, BELOW the 0.995 bar. The reliable near-collinear case is an AFFINE COPY (r = 1.000000).
  • A hard-coded 3× multiplier in a cross-talk test a 64-axiom fixture could not carry (measured 2.64×). Replaced with the EVT expectation √(2 ln K).
  • Assumed "I" is identity. Measured: apply_op("1234","I") = "2345" — I is INCREMENT. My assertion was about semantics I never measured. The real collision is C being idempotent: C, CC, CCC all give "1111" (36 collision groups measured).
  • subprocess(shell=True) is cmd.exe on Windows — bash line continuations broke pytest args; $VAR and coreutils timeout do not resolve.
  • Plus: a 2-D/1-D torch.outer, a d-length query against a d_H-length wave, axioms built at the wrong dimensionality, a test path off-by-one, and a ragged torch.tensor.
