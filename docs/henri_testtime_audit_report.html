4. Two root causes, both measured

D-ZO-COLLAPSE — the beta scale does not match the logit domain.
The CCCP attention is logits = beta·⟨z,p⟩ with unit-norm random patterns, so ⟨z,p⟩ ~ N(0,1/D) and |cos| ~ 1/√D ≈ 0.0156. At beta=26.10 that gives max |logit| ≈ 0.5, softmax entropy H/lnN ≈ 0.97 (near-uniform), so att @ patterns converges to the bank mean. The document's beta assumes a cosine near 1 that a random 4096-d bank cannot produce. This is the same defect class as D82/D85: a Hopfield block whose logits do not match the formula's stated domain.
D-BANK — the swarm matched a random bank, not the corpus.
build_axioms() updated only the veto. Measured: axiom_bank is identical before and after that call, and bank-vs-corpus |cos| max = 0.0418 ≈ 4/√D (unrelated). So the swarm resolved every input against 8 seeded random unit vectors while the veto — the component that did receive the corpus — reported dark for every query. The two halves of the system were looking at different worlds.
