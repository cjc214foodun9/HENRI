1. The direct answer

Discipline: yes, and it is now real.
Order: no — we are building machinery on a substrate with no learned structure.

The seven mechanisms measured this program have each produced a bounded, falsifiable verdict. That is genuine progress, because a control that can fail now gates every claim. But we have spent many turns falsifying mechanisms that were never wired to a scored task. Three separate measurements now agree on one root cause, and that cause sits upstream of everything the blueprint wants to build.

The root cause, stated once

HENRI has no transferable representation. The ingress is an explicitly frozen random projection. It carries surface form and weak lexical signal — not a rule the readout can generalize from. Every subsystem in the six-part blueprint sits downstream of that absence.

3. The decisive root-cause experiment

The M4 failure alone cannot say where the defect lives. A readout can fail because the representation is empty, or because the readout is wrong. So I held the wave fixed and swapped only the readout:

pre-registered bar = max(floor, best control) + 0.05 0.1671

What this establishes

  • OBSERVEDThe readout is a genuine defect. A linear probe scores 0.1339 where the 414M production readout scores 0.0000 on identical features — a 16× gap.
  • OBSERVEDThe wave carries real signal. The ridge probe beats its own shuffled-label control 0.1339 vs 0.0089 — a 15× separation. The signal is weak, but it is not noise.
  • NOT CLEAREDM4-G1 still fails. 0.1339 < 0.1671. Fixing the readout is necessary and insufficient. The binding ceiling is representation quality.

Two further facts settle the shape of the fix:

  • WaveTextGenerator sets ingress.requires_grad_(False). The ingress is explicitly frozen. Gradient reaches the readout only.
  • Programs tokenize by character: IRC → [73,82,67], CRI → [67,82,73]. Composition is expressible. There is no opaque-token blocker — and order is encoded (cos(w(RC), w(CR)) = 0.0).

4. Your intuition was measurable — and it is correct

You said most inference will be useless noise, and the network's job is to sort it. That is testable, and I tested it with the metric this program was missing: coverage@k — is the correct token even in the candidate set?

Read this as a ceiling, not a score. Coverage saturates at ~0.43–0.46. That means no reranker, veto, or resonator can ever exceed ~46% on this task, because the right answer is absent from the candidate set more than half the time. Your "sort the noise" architecture is the correct shape — and this number is exactly where it must be applied. It is also the honest bound on what any downstream subsystem can deliver today.

5. The recurring defect class — measured twice

No measurement may sit downstream of an operator that mixes the candidate with the bank.

  • Q4: s(q) measured after the CCCP swarm projection → saturated at ~0.99 for 100% of inputs. Q4 could never fail.
  • The veto: Δ_Sagnac measured on psi_conv (post-CCCP) → 0.0036–0.0171, passing every family including random text. The veto could never fail.

Same defect, twice, in two different subsystems. The Phase-1 coupling supplies the missing pre-projection term; without it the veto cannot reject anything. This is why the coupling improved dispatch — and why its attribution is still weak.

6. Correction — a claim I retract

Earlier this turn I read the training log wrong. The stderr line m4 step 100 ce 3.2826 is unigram_ce, printed as a reference — not the model's loss. The receipt shows loss_first 5.9587 → loss_last 0.000538.

So the gradient is not severed, and "the loss is flat" was false. The correct statement is the opposite and more damning: the readout trains to completion and memorizes (train exact-match 1.0), then scores below the unigram floor on held-out data.

8. Recommended program order

Substrate before machinery. Each step has a kill test that can fail.

StepDo Kill test
1 Make the ingress learnable. Unfreeze it on the M4 path behind a default-OFF flag. Gradient demonstrably reaches an ingress parameter and that parameter changes. A frozen flag or a severed path fails the test.
2 Make M4-G1 passable. Held-out token accuracy must beat both the unigram floor and the shuffled control, across ≥3 pinned seeds. Pre-registered bar, margin-ratio criterion, not a scalar threshold. Currently 0.1339 vs bar 0.1671 → fails.
3 Make the veto a real gate on that task, and re-run the Phase-1 coupling. ATTRIBUTABLE must become True: the coupling must beat the shuffled-score and random-score controls by the pre-registered margin.
4 Raise the focus ceiling. Coverage@5 is 0.4286; the architecture must propose better candidates, not better rerank them. Coverage@5 must rise above 0.4286 and top-1 must rise with it.
5 Only now: test-time learning. Anything the veto rejects must be learned from. Requires a scored task from step 2 to show improvement against. Without it, test-time learning is unfalsifiable.

On the omni-verifying Sagnac/D2NN request. A D2NN phase-mask interferometer is a fabrication program, and it needs a ground-truth label to learn from. "Anything rejected must be learned from" is degenerate without one — the veto learns to reject everything, or collapses to the prior. The design is sound as an architecture; it cannot be judged until step 3 exists. Physical BTO/D2NN hardware and a CPU emulation at dim=4096 are different claims and must never be conflated.
