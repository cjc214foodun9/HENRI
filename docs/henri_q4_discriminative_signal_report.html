The discriminative signal: Q4 can now fail

HEAD a404125 = origin/main = origin/feat · 7/7 gates green · ledger 1956 · CPU dim=4096, small config
Built, wired, pinned, measured. A pre-projection membership score now separates inputs the bank contains from inputs it does not. The shuffled-bank control collapses it, and it transfers across five ingress seeds with a single threshold. Q4 can fail.

And it is not intelligence. The gate is a graded lexical membership meter. It makes HENRI able to abstain. It does not give HENRI understanding. Both statements are measured below.

1. The defect this fixes

Last turn's Q4 compared a post-projection score against a pre-projection baseline. The swarm's CCCP projects every wave onto the stored bank, so post-projection similarity saturates:

MeasurementValueReads as
Post-projection similarity ≥ 0.95, fraction of inputs (K4)1.0 100% — nothing can ever be rejected
Post-projection mean≈ 0.99the projection is the confound

Reading the same statistic before the swarm runs recovers the information the projection destroys.

8. Defects I found and fixed in my own work this turn

  1. v1 AUC was trivial. I compared each family against random waves, which are orthogonal to the bank by construction — so every AUC was 1.0. Replaced with the shuffled-bank ablation, which can fail.
  2. Identity permutation. torch.randperm can return the identity (~34% over 10 items), reproducing the original in-bank string and faking a 1.0000 out-of-bank score. Now rejected with a deterministic fallback.
  3. Wrong-population comprehension. My "out-of-bank max" still included the positive control, so it read 1.0000 and falsely reported failure. Fixed.
  4. Non-deterministic instrument. The ingress draws from the global RNG unless pinned; two runs hashed differently. All harnesses now pin ingress_seed. Production default unchanged.
  5. A flaky test. T3 asserted a semantic threshold (0.5); the score is 0.5725. Rewritten to test the mechanism — abstention must follow the threshold — on both sides of the actual score.
  6. Promotion order. An earlier pipeline pushed d86c4d6 to main while its own regressions returned rc=1 (it spawned a torch-less interpreter). Content was re-verified green afterwards, but the order was wrong. The final pipeline gates first, then commits.

9. Where the core claim stands

  1. Q4 can fail. That was the stated blocker, and it is removed. HENRI can now say "this is not in my bank."
  2. It is a membership meter, not understanding. Necessary, not sufficient. The honest reading of the numbers above.
  3. What remains. The six-subsystem gap is unchanged: learnable ingress, action-conditioned transitions, iterative resonator descent, Zone C persistence, sensorimotor grounding, grammar-constrained egress. This turn closed one mechanism, not the program.
  4. Next discriminating experiment. Wire the gate into the Sagnac veto — currently a verdict nothing consumes — and measure whether abstention improves any scored task. If it does not, the gate is a diagnostic, not a capability.
