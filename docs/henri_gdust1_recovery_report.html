4. What this does and does not establish

OBSERVED On this single linear layer with a fixed readout, the zeroth-order node-perturbation estimator aligns with autograd at cos 0.987 when the population is 16,384. It requires no backward pass.
SCOPE LIMIT This is one linear layer plus a fixed readout, not a full-model replacement for backpropagation. Nothing here licenses removing the training path or claiming model-wide equivalence.
DEVICE henri_core has no CUDA plumbing. The estimator path is CPU-only; the RTX 5090 was not used for the arithmetic. The Vast host supplied 192 CPU cores. G-DUST-2 (VRAM) and G-DUST-5 (latency roofline) stay BLOCKED — no telemetry claims.
COST K=16384 needs ~386 s per seed on 192 CPU cores, and the upstream headline configuration is 16,384 draws across 8 GPUs. This is not yet sub-microsecond, continuous, or cheap.
