# HENRI-STE-V1 language and visual protocol

## Academic foundation

Use ASD-STE100 principles for technical prose. The official source is Issue 9, 2025-01-15.
The user selected soft word targets. This policy adapts principles; it does not certify complete standard compliance.
The supplied framework names Issue 8 and contains incorrect approximation/safety/OCSF mappings. See source-audit.md.
Do not reproduce the official PDF or full dictionary in this repository.

## Technical decision

Keep the cache contract first. Add one fixed language directive to HENRI skill bodies, SOUL, the bundle, and task packets.
The existing roster, bundle order, and frozen A/B/C remain unchanged. New sessions load the disk edits.

- Operational prose: short active sentences, one task, explicit actor, defined term, evidence class, and next gate. Soft targets: 20/25 words.
- Formal content: exact code, equations, schema keys, argv, identifiers, hashes, paths, units, and source quotes.
- Visual/HITL: editable Draw.io plus accessible HTML for substantive reports and decisions. Explanatory prose, layout, and graph richness stay unrestricted.

Keep urgent safety text and viewer/accessibility fallback in plain text. Use WARNING for injury risk and CAUTION for damage risk.
A button or diagram is not an approval. Use the real human approval transport.

## Real consumers

- Active-profile scripts/henri_language.py reports selected pattern/count findings. It never rewrites text, calls a model, or grants permission.
- scripts/henri_moa_packet.py adds a fixed language guide and exact task tail. References need the guide because they do not receive SOUL.
- The existing henri-control-plane hook appends the guide to a new-session user tail. It leaves the system prefix alone.
- The existing OpenShell consumer assesses an optional operational description. It preserves argv and still requires the real proof/runtime gates.
- The committed ContextPacker exercised a fixed policy and changing task tails. It is not a production scheduler claim.

## Usage

Through Hermes terminal:

```bash
python "$HERMES_HOME/scripts/henri_language.py" --file "<text>" --track operational --mode procedure
python "$HERMES_HOME/scripts/henri_language.py" --file "<text>" --track visual
python "$HERMES_HOME/scripts/henri_moa_packet.py" --task-file "<exact-task-text>"
python "$HERMES_HOME/scripts/henri_openshell.py" --description "Read the process identity." -- /usr/bin/id
```

These examples do not grant permission or revive a Completed sandbox. Verify actual runtime state before use.
Style findings return ADVISORY. Malformed envelope or size errors return BLOCKED. Do not label NO_SELECTED_FINDINGS as full compliance.
Noun groups, part-of-speech meanings, complete dictionary coverage, semantic truth, and technical term approval require review.
