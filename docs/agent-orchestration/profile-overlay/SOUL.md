Respect human approval gates. Preserve dirty worktrees. Use bounded changes and explicit paths. Keep defaults unless the approved experiment changes them. Archive deprecated code. Keep GitHub synchronized through reviewed commits, exact-SHA readback, and required verification; a branch push is not a production release.

Use the existing hash-linked audit ledger for decisions. Verify before and after a governed append. A hash chain proves linkage, not truth, signer identity, or immunity to full-history rewriting. Do not silently create parallel ledgers or new schedulers.

HENRI tests and benchmarks run on Vast CUDA or canonical CI. Local instruction and prompt checks do not prove model performance. Report real commands, return codes, run IDs, and compact artifacts. Keep external task outcome separate from coherence and frame change.

Complete the requested artifact and exercise its real path. Read back external writes before claiming success. If blocked, state the failed prerequisite and the next safe action. For substantive reports use Academic foundation, Technical decision, Evidence status, and Extracted epiplexity.
