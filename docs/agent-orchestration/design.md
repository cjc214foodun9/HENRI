# Approved bounded design: cache, diagrams, Jev, OpenShell

Scope approval: cache-first instructions and Draw.io scanner override; Jev advisory caller/live probes; local WSL OpenShell pilot. No main merge, Vast provisioning, mathematical changes, schema changes, production credentials, or active-session backend/roster swap.

## Mechanism and hypothesis

Stable initial prompt bytes and unchanged provider/model routes permit provider KV reuse. Dynamic state is appended; cached relevance is retained only when valid. Hypothesis: lower billed repeated input at equal evidence/decision quality. Hashes alone do not measure this. Jev handles finite semantic judgments via its real Decisions API; exact-request local memoization removes repeated API calls. Jev never authorizes security or capability claims. OpenShell checks policy containment and enforces qualified Linux kernel boundaries. Draw.io creates editable, source-backed diagrams, not proof of runtime integration.

## Data path

Stable session/bundle → deterministic evidence → Jev typed advisory → acting root + existing approvals → real OpenShell effective policy/prover → qualified sandbox execution → observed receipts → external verification where relevant → ledger. MoA receives a fixed scaffold and a compact task tail; references run in parallel and cannot judge unseen peer outputs. Human-visible diagram shows observed/proposed/blocked layers.

## Limits

Pin Jev typesafe/jev-1.13 and OpenShell v0.1.2. Two small Jev routing probes plus one denial-advice control. No bulk saturation request until a real consumer needs it. Local application cache lifetime ≤300 s by default, key includes full state/model/rubric. <50 ms API latency and universal calibration are not accepted claims. OpenShell WSL support is experimental. One local sandbox, no host data mount, no credentials, manual policy approval, no GPU claim. Missing binary/proof/runtime blocks dispatch.

## Cheapest kill checks and acceptance

- Cache: verify static prefix preserved on real Hermes loaders and request paths; two useful same-prefix provider requests with actual cache usage; label absence/miss instead of a guaranteed hit.
- Diagram: full upstream supporting tree restored at pinned commit, editable artifact built, structural validator and semantic inspection, actual HTML preview.
- Jev: live generation ID and typed response; repeat exact request hits local memo without second generation; changed state invalidates cache; invalid response/choice rejected; every result says authorization=false.
- OpenShell: checksum/version, within_boundary control, exceeds_boundary control, invalid blueprint policy rejection, explicit kernel qualification, allowed execution, forbidden filesystem/network denied. CLI-only success is not containment success.
- Delivery: frozen A/B/C unchanged, active-profile paths verified, exact changed-file inventory, ledger verifies, review branch only. CUDA/model changes require separate remote gate.

## Rejected blueprint steps

1. route_task uses keywords plus fabricated confidence, not Jev. Replace with real Decisions call and response provenance.
2. Vast manager fabricates instance ID/metrics; never execute or publish as an observed run.
3. Prover failure falls back to structural keys. This accepts violations. Only real within_boundary with required coverage can pass.
4. Gateway TOML/policy schema and prover verify --contract do not match current API. Use official schema and check candidate --boundary.
5. Sagnac ≤0.001 and Kuramoto ≥0.95 cannot establish external task success; do not replace live stage-specific constants.
6. Landauer's erasure bound does not entail a software DAG logging law. Active-inference analogies do not prove security. No formal guarantee beyond modeled policy coverage and measured kernel behavior.
7. Naked 0.70/0.80/0.85 thresholds conflict across specs and are not calibrated HENRI error bounds. Pilot advice escalates conservatively; no zero false-negative claim.
8. Dockerfile install || true is fail-open. No suppressed install failure; no stale CUDA/PyTorch pins or bare-metal claim for container rentals.
