## 1. Problem statement

F2's calibrated codebook collapsed on held-out env `wa30`: calibration P@1 0.8588 → held-out P@1 0.18.
The operator learned the calibration marginal (ACTION4) instead of a state-conditioned unbinding rule.
Basin volume ∝ N_a·exp(β·μ_a) makes retrieval default to the empirical mode when the test
distribution shifts (post-mortem §1.1). Corpus root cause: 3 envs, N=327, test H(A) ≈ 0.65 nats vs
max ln 7 = 1.9459 nats.

F3 replaces the corpus and the evaluation protocol ONLY. The codebook math, ridge, temperature,
and rank are frozen from the sealed F2 spec; the directive explicitly rejects tuning
(§3: no sweeping β ∈ {16,32,64}, no λ/r changes).

## 2. Mechanism (unchanged from F2 — frozen)

- Codebook `M = A·B`, `A = Yᵀ(XXᵀ + λI)⁻¹ ∈ ℝ^{V×N}`, `B = X ∈ ℝ^{N×D}`; V = 7 actions, D = 65,536.
- Ridge λ = 1e-3 FROZEN at seal; β = 8.0 (Ramsauer 2008.02217); rank r = 128 factorized
  `M = U_M·V_M†` (post-mortem §2.1; 1.75 MiB at V=7).
- Snap: `z = Softmax(β·Re(Ψ·M†))·M`.
- Thin-SVD dual solve; **no dense [D,D]**; float32 accumulation; zero trainable parameters; no-BPTT.
- **Zero hyperparameter deltas vs F2.** Any proposed delta = typed amendment requiring approval (K6).

## 3. Capture protocol (authorized live capture, passive)

- Mechanism: production-run trajectory-bank capture (Phase 8.32b pattern,
  `henri_trajectory_bank.py`; passive `(o_t, a_t, o_{t+1})` logging; `data_source=authorized`;
  `store_next_wave=true`). Same authorized-capture lineage as the F2 bank.
- **Env selection is NON-ADAPTIVE:** the first 12 environments in the live Arcade API
  enumeration order (deterministic; directive-named pool includes ka59, sk48, sc25, g50t,
  cd82, sb26, wa30). No selection by telemetry.
- Per-env budget: ≥ 100 records/env, cap 150/env; total N ∈ [1200, 1800].
  Per-env seed derived deterministically from run_id (pinned at seal). `truncated=false` on all episodes.
- **Entropy gate (VALIDATION, not selection):**
  - Bank-level `H(A) = −Σ_a p(a)·ln p(a) ≥ 1.70 nats`;
  - Per-action support `N_a ≥ 30` for every action in the 7-action vocab;
  - Cross-env frame-delta variation `CV_diff = std(μ_e)/mean(μ_e) > 0.20`, with
    `μ_e = mean(|Δgrid|)` per env.
  - Failure → `BLOCKED_ENTROPY_GATE` / `BLOCKED_DIVERSITY`; capture artifact preserved;
    env re-selection requires approval. **No policy steering, no oversampling, no synthetic
    trajectories** (zero-pretraining + provenance invariant).
- Artifacts: `trajectories_<run_id>.npz` (`psi`/`next_wave` float16 [N,D], `actions_onehot`
  uint8 [N,7], `action_names`), `.jsonl`, `_manifest.json` (schema `henri.arc-trajectory-bank.v2`:
  adds per-env counts, per-env action histograms, H(A), CV_diff, seed, fold-manifest digest).

## 4. Grouped 4-fold cross-validation (sealed at split time)

- Disjointness unit: ENVIRONMENT. All episodes of an env live in exactly one fold — never split.
- 12 envs → 4 folds × 3 held-out envs; 9 train envs per fold.
- Fold assignment deterministic and NON-ADAPTIVE: envs sorted lexicographically by env id;
  `fold = index mod 4` (pre-registered; generated by `f3_split_seal.py` in a generation-only
  process, no model/checkpoint load; receipt pins fold-manifest SHA-256, seed, per-fold env
  lists + record counts, `single_use=true`).
- Per-fold evaluation: calibrate on the 9 train envs ONLY; held-out P@1 on the 3 test envs.
  A fold's held-out records are never in any calibration set (group-disjoint by construction).
- Aggregate metric: **macro mean over folds** (mean of per-fold held-out P@1), never pooled
  records — pooling can mask single-env collapse (the F2 failure class).

## 5. Gates (acceptance)

- **G1** (generalization): macro held-out P@1 ≥ 0.99 AND min-fold held-out P@1 ≥ 0.95
  (min-fold guard prevents one fold masking collapse).
- **G2** (per-action coverage): every action with N_a(test) ≥ 10 in a held-out fold has
  per-action held-out P@1 ≥ 0.80; actions with fewer test records are reported
  coverage-limited, not scored.
- **G3** (non-vacuous syntactic validity): ACTION6 coordinate-payload format validity ≥ 0.99.
  Redefinition note: F2's G2 (argmax always legal at V=7) was disclosed VACUOUS in the sealed
  receipt; payload-format validity is a real egress-boundary check.
- **G4** (beats marginal predictor): macro held-out P@1(F3) − macro held-out P@1(train-marginal
  predictor) ≥ +0.05. The train-marginal predictor (argmax of the fold's training action
  marginal) is the causally decisive comparator for the F2 mode-collapse failure. The legacy
  BPE-head comparator stays `BLOCKED_NO_ACTION_TOKEN_MAPPING` — not re-opened.
- **G5** (default-OFF differential): `HENRI_F3_EGRESS=0` → byte-identical pipeline
  (differential, not flag-read).
- **G6** (eligibility boundary): codebook alone NEVER grants score eligibility.

## 6. Kills

- **K1**: macro P@1 < 0.99 OR min-fold < 0.95 → carrier KILLED, default-OFF preserved.
- **K2**: margin vs train-marginal < +0.05 → KILLED (mode-collapse return).
- **K3**: entropy gate failed (H < 1.70, N_a < 30, or CV_diff ≤ 0.20) → capture INVALID;
  no calibration; `BLOCKED_ENTROPY_GATE`.
- **K4**: no engagement telemetry (no `f3_egress_status`, no per-fold consumption) → KILLED as mock loop.
- **K5**: dense [65536,65536] allocation in the calibrated path → KILLED (dense-ban violation).
- **K6**: any hyperparameter delta vs F2 without an approved amendment → KILLED (directive §3).
