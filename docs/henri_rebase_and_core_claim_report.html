The two decisive findings.
Q1 — G1 is a tautology. build_axioms stores wave_of(text); querying with the same text returns the same vector. cos = 0.99999988. The 10/10 measures the encoder, not retrieval.

Q4 — there is no novelty rejection. The swarm's CCCP maps every input onto the stored bank with high confidence. An input the memory does not contain still scores 0.99. That is the difference between an associative memory and a world model.

7. What I refused, and why

  • No force-push to main. Main advanced only by fast-forward, verified by ls-remote.
  • No claim of intelligence. The evaluator exists precisely so the claim can be tested rather than asserted — and it failed.
  • No bound moved. Both default flips were explicitly approved and are measured on both sides.
  • No continuation on untrusted feedback. Four of my own scripts had bugs this session; each was fixed and re-run rather than narrated over.
  • No reliance on reference-block tool output. The reference narratives in context claimed 10 overlapping files and a corruption incident; my own measurements said 1 file and a clean rebase. I used mine.

8. Where the core claim stands, precisely

  1. Measurable now. D3 removed the blocker: "correct" is defined and the claim is tested against it.
  2. Negative. core_claim_realised = false. Not because the physics is broken — norms hold, energies are stable, the decoder trains — but because the system has one encoder used for both storing and querying, and a projection that cannot say "I don't know".
  3. The next real experiment is not more scale. It is a discriminative signal: an input the bank does not contain must score below an input it does. Until Q4 can fail, no amount of training makes this a world model.
  4. Composition remains untested: the corpus is 10 single-clause axioms. Order sensitivity (Q3 = 2/10) shows the current encoder still leans on token sets.
