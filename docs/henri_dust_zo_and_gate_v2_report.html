Academic foundation

Node-perturbation credit assignment is old and sound (Widrow & Lehr 1990; Werfel et al. 2003). The supplied specification restates it for transformers. Its §2.2 Taylor argument is correct: for ỹ = y + σa, a ~ N(0,I), the centred drop c = L̄ − L(ỹ) gives E[ĝ] = ∇yL, hence E[ĜW] = ∇WL. That is an unbiased estimator, and it needs no backward graph.

What the specification does not establish is the part that matters here: that K=256 suffices at 65,536 dimensions. Its own source contradicts the performance framing. The upstream repository (qlabs-eng/dust @ 2fdb01ba, MIT) states its headline runs use population 16,384 on eight GPUs; K=256 is the small single-GPU configuration. The README also says the minimal implementation "omits execution optimizations". So the doc's latency table is aspiration, not measurement.

Aggregate rank is constant. G-U4 scores a linear readout of the aggregate pooled structure, so it tracks aggregate rank — and cannot separate the arms at full scale. That is the mechanism behind the K-B6 full-scale result. Confirmed instrumentally: the slot sweep reports rank_constant = true across dk_target {4, 8, 16, 32, 64}.

Reachability — where backprop actually stops

OBSERVED from exp_gradient_path.py:

system.wave_of(...)        requires_grad = False
ingress.encode_text(...)   requires_grad = False
backward raised: RuntimeError ... does not require grad
ingress params REACHED by backward: NONE
severing ops: argmax | int() | no_grad | frozen buffer lookup
decoder tensors with grad: 29 | max |grad| = 180.1 | loss 5.7631 -> 3.8226
Honest scope. Backpropagation is severed only at the ingress/wave boundary. The decoder path trains normally (29 tensors, max |grad| 180.1, loss 5.76 → 3.82). The claim "backpropagation is an artificial crutch" is therefore partly true and partly false: it is a real wall at the interface to the physical wave core, and it is not a wall for the digital model. That boundary is exactly where a forward-only estimator has honest value.
