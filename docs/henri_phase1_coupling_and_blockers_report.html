Attribution is partial: it beats both controls on accuracy, but the pre-registered near-miss criterion did not reach its threshold. Both halves are reported below.

10. Where this leaves the program

  1. One mechanism closed, and honestly. The coupling exists, is default-OFF, is measured, and its benefit is partial. That is the true state.
  2. The real blocker is now precise. There is no working scored task for the wave model. M4-G1 is that task and it fails. Subsystems 1–3 need it before any of them can be judged.
  3. Next discriminating experiment: make M4-G1 able to pass — fix the readout path until held-out token accuracy beats the unigram floor and the shuffled control. Until then, subsystem work is decoration.
  4. I did not build the six subsystems. Doing so in one turn would produce untested scaffolding, which the architecture rules forbid. It would also break the per-seed calibration every Q4 receipt depends on.
  5. I did not claim "perfected". HENRI is a wave substrate with one working coupling, one vacuous gate now made able to fail, and no working task.
