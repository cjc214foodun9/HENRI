**Carrier:** delta_qfhrr_associative_memory.py — factorized low-rank delta-rule associative memory, r=8, D=4096, decay γ=0.985, Triton kernel. **Supersedes Egress-2 as active work** (Egress-2 artifacts remain untracked, isolated, never claimed).

## Ratified contracts (user-provided, verbatim semantics)
- **C1 (Module Architecture):** `delta_qfhrr_associative_memory.py` implements factorized low-rank delta updates M_t = U_t V_t^⊤ (r=8, D=4096).
- **C2 (Zero Trainable Backbone Parameters):** all online adaptation exclusively in dynamic memory state (U_t, V_t); static projection weights frozen.
- **C3 (Single-Use Evaluation Split):** `heldout55_deltamem1` (520 tasks, seed 94126).
- **C4 (Delta-Rule Error Reduction):** on non-stationary task streams, delta-rule reduces prediction error e_t ≥ 40% vs standard Hebbian (M_t = M_{t−1} + v_t k_t^⊤).
- **C5 (Phase Linewidth Stability):** across 1,000 continuous online updates with γ=0.985, R_sync ≥ 0.90.
- **C6 (Execution Latency Ceiling):** combined readout + delta-update step < 15.0 μs on host GPU.
- **C7 (Memory Footprint Limit):** ≤ 128 KB (2×4096×8×4 bytes).
- **C8 (One-Step Skill):** reranker + δ-qFHRR memory satisfies SSR_eval ≤ 0.35.
- **C9 (Multi-Step Rollout):** 5-step unrolled prediction SSR_rollout,5 ≤ 0.70.
- **C10 (Sagnac Veto):** readouts with Δ_Sagnac > 0.35 trigger e_t → 0 (suppress invalid engram writes).
- **C11 (Deterministic Execution):** output memory states + telemetry byte-identical across independent CUDA runs.
- **C12 (Fail-Closed):** if latency > 15.0 μs or R_sync < 0.90 → DELTA_MEM_REJECTED; retain baseline Dual EDMD transition model.

## Pre-seal amendments (recorded, both hashes; no silent edits)
- **A1 (C7 arithmetic):** the parenthetical computes 2×4096×8×4 = 262,144 B = **256 KB**, not 128 KB. Binding gate = stated limit 128 KB, satisfied by **bf16 factors** (2×4096×8×2 B = 131,072 B = 128 KB). fp32 factors (256 KB) reported as diagnostic. C7 gates the Triton kernel; exactness contracts (C4/C5/C8/C9/C10) gate the fp32 reference path.
- **A2 (C5 R_sync):** R_sync = |(1/D) Σ_j exp(i 2π φ̂_j/256)| over the D components of the quantized readout phase field φ̂ = angle(Ψ̂_t), Ψ̂_t = M_{t−1} k_t; measured at step 1,000 of the heldout stream (520-block stream run twice = 1,040 steps).
- **A3 (C8/C9 SSR):** stage-0c protocol: SSR_eval = ||(Ŷ−Y)V||_F / ||Y·V||_F (one-step, top-r basis from calibration-only first 40% of stream); SSR_rollout5 = ||Ŷ_5 − Y||_F / ||Y||_F (5-step open-loop, absolute normalized).
- **A4 (C4 stream):** non-stationary stream = 13 family blocks (seeded random family order, 40 tasks/block) of reranker canonical-code embeddings (task["code"], D=4096, L2-norm). e_t = ||ψ_{t+1} − M_{t−1}ψ_t||₂. Hebbian arm: γ=1, η=0.1, no error-correction. Reduction = 1 − mean(e_delta)/mean(e_hebbian) ≥ 0.40.
- **A5 (C6 host):** Vast RTX 5090, CUDA events, 10k iterations, mean < 15 μs (p95 reported). Two-kernel fused step (K1 readout+reductions, K2 update).
- **A6 (C10 metric):** real-space Sagnac S = 0.5(1+⟨Ψ̂,ψ⟩), Δ = 1−S ∈ [0,1]; Δ > 0.35 → e_t := 0, write suppressed, counter incremented (fail-open: no deadlock).
- **A7 (veto null-readout):** a NULL readout (‖Ψ̂‖≈0, e.g. zero memory state) carries no destructive interference; veto applies only to non-null readouts whose phase conflicts (Δ > 0.35). Otherwise the memory could never learn (every first write vetoed).
- **A8 (consumer embeddings, OBSERVED 2026-08-24):** `NativeQFHRRReranker.encode_code` returned raw uint8 Z_256^4096 phase vectors (linalg.vector_norm: Got Byte → RuntimeError). Fix (bounded, pre-seal): cast to float32, L2-normalize, return float32 unit vector (matches the Egress-2 T3-verified contract and prereg A4's L2-norm stream). Re-verified manifest hash changes → reranker manifest updated.
- **A9 (frozen projection, OBSERVED 2026-08-24):** the sealed design froze V = 0, which makes the factorized memory DEAD (a_t = 0, U never learns, readout always null → C4/C5/C8/C9 trivially fail). C2's wording ("static projection weights shall remain frozen") implies V is a FROZEN SEEDED projection, not zero. Amendment: V₀ = seeded orthonormal projection (seed 20260824, QR-normalized, sign-canonicalized), U₀ = 0; reset() re-zeros U only, V stays frozen; Triton kernel mirrors (bf16 storage, fp32 solve).
- **A10 (C5 vacuity + stream binding, OBSERVED 2026-08-25 pre-measurement):** (a) A2's R_sync = |(1/D)Σ_j exp(i2πφ̂_j/256)| with φ̂ = angle(Ψ̂_t) is VACUOUS on the ratified real-valued readout path (A6/A8): angle(real) ∈ {0, π} and exp(i2πφ/256) ≈ 1 for both → R_sync ≈ 0.999 for ANY memory, including the zero memory (a dead memory passes C5). Amended (pre-measurement, gate unchanged ≥ 0.90): R_sync := mean over steps 901–1,000 of S_t = 1 − Δ_t, where Δ_t is the A6 real-space Sagnac delta (readout vs observed next embedding). Zero memory ⇒ Δ ≈ 0.5 ⇒ R_sync ≈ 0.5 → FAIL (non-vacuous; a live memory that predicts coherently ⇒ Δ small ⇒ R_sync → 1). A2's formula is reported as diagnostic only, labeled VACUOUS. (b) A4's "13 family blocks, 40 tasks/block" must be reconciled with the sealed split: fid sequence audited (seal `5ac57d15…`, audit below). Binding: the C4/C5/C8/C9 stream = sealed split task order, run as a cyclic stream of length 520 for 2 epochs (1,040 steps; step t uses k = ψ[t mod 520], v = ψ[(t+1) mod 520]). Gate values unchanged.
- **A11 (evaluator corrections, ratified 2026-08-25 pre-sealed-run; doc before `decd3dba…`):** (a) Hebbian comparator is the SAME-SUBSPACE factorized memory: same frozen seeded rank-8 V (seed 20260824), γ=1, η=0.1, NO error correction (M += η v k^T within span(V)). Dense D×D Hebbian is infeasible under the mandatory rank-r factorization (C1) and is NOT the comparator. (b) C4's error is the PRE-update, PRE-VETO residual ‖ψ_{t+1} − M_{t−1}ψ_t‖₂ (logged `raw_error_norm`); the veto-zeroed write error (`write_error_norm`) is C10 governance telemetry only — never C4 (a veto-zeroed stream would fabricate improvement). (c) C6's binding input is the HOST-VISIBLE mean (C6 text: "on host GPU"); CUDA-event mean remains diagnostic. Receipt parser binds `c6.host_visible_mean_us` and `c7.bf16_bytes`. (d) Receipt validation is pass-closed: refusal unless the receipt carries the sealed keys, C7 bf16 gate passed, C11 determinism equal, all fp32-equivalence cases passed, and GPU is the RTX 5090 target. ## Sealed design decisions (frozen before code)
1. **Recurrence (reference, exact):** k_t = ψ_t (obs embedding), v_t = ψ_{t+1}; readout Ψ̂_{t+1} = M_{t−1} k_t; e_t = v_t − Ψ̂_{t+1}; M_t = γ M_{t−1} + η e_t k_t^⊤, factorized M = U V^⊤ with U,V ∈ R^{4096×8}, γ=0.985 (USER_SPECIFIED, ratified C5; paper has trained gates β_t, λ_t=1−β_t), η=0.1 (pre-registered). Factorized update (exact within row span of V): U_t = γ U_{t−1} + η e_t ((V_{t−1}^⊤ k_t)^⊤ (V_{t−1}^⊤ V_{t−1})^{−1}); V_t = V_{t−1}. V^⊤V ∈ R^{8×8} tiny, exact inverse.
2. **Init/reset:** U_0 = 0, V_0 = frozen seeded orthonormal projection (A9; M_0 = 0 since U_0 = 0); reset() re-zeros U only; per-segment reset supported.
3. **dtype/accumulation:** fp32 reference (deterministic fixed-order reductions); Triton kernel fp32 + bf16 variants (bf16 = C7 path). Overflow guard: e_t norm > 1e6 → clamp (pre-registered, counted).
4. **Default-OFF:** HENRI_DELTAMEM=1 enables; otherwise module returns byte-identical passthrough (asserted).
5. **Zero-trainable:** U,V are buffers (no requires_grad, no optimizer); static codebook/projections frozen (reranker manifest asserted `e400e7e9…`).
6. **Triton equivalence tolerance (pre-registered):** kernel vs reference max abs error ≤ 1e-4 (fp32) across: seq len {1,8,64,1000}, r {2,8}, D {64,4096}, batch {1,4}, reset boundaries, 1,000-step repeated decay, non-contiguous (rejected explicitly with clear error). bf16 equivalence reported (tolerance 5e-3).
7. **Determinism scope (C11):** memory states + telemetry bytes identical across ≥2 independent CUDA processes on the identical input; raw timestamps excluded. No atomics; fixed-order per-block partial reduction.
8. **Consumer (causal):** the verified NativeQFHRRReranker (Egress-2, manifest `e400e7e9…`) embedding stream over heldout55_deltamem1; memory readout = next-observation prediction; SSR/error gates are the external metrics. Memory that changes nothing = DIAGNOSTIC_ONLY/NO_EFFECT per C4–C9 gates.
9. **Verdict precedence:** DELTA_MEM_ACCEPTED iff C4–C11 all pass. C12 fail-closed: C6 or C5 fail → DELTA_MEM_REJECTED (named). Any C4/C8/C9/C10/C11 fail → DELTA_MEM_REJECTED with failing contracts listed. Baseline Dual EDMD transition model remains production default in all cases.
10. **Incremental persistence:** evaluator writes per-task JSONL before any aggregation; --expect-count guard; exposed split → quarantine + never replay.
