# HENRI Agentic Graph Migration

The legacy root module `henri_langgraph_executable_agent_engine.py` is a simulated design demonstration. It contains hard-coded research, approval, execution, and telemetry values. It is not a production route.

Production orchestration uses the bounded control-plane primitives under `HENRI V2/agentic_graph/`. The runtime requires deterministic evidence receipts before verified promotion and permits only leaf-local bounded repair.

The legacy module remains preserved for historical inspection. Its public builder is fail-closed.

## Activation status

The bounded runtime is implemented and tested as a repository control plane. It is not yet wired into Hermes model dispatch, TrustGraph, CUDA execution, or global `config.yaml`. The Hermes audit found no verified standalone workflow-profile injection API. The static workflow profile is therefore a source-controlled specification and is loaded through the HENRI graph integration path when that path is explicitly invoked.
