## Hypothesis

Training the production `LowRankCoupledTransition` on real known-transform
transitions (encoder-wave pairs via `train_transition_step`) descends the
Sagnac transition loss and restores directional action signal to the EFE
terms at D=65,536, so the true transform candidate reaches rank ≤ 2 (partial)
or rank 1 (spec PASS) under the COMPLETE production selection path.

## Experimental design (CUDA, RTX 5090, D=65,536, GPU-exclusive, Zone C prod)

- **Training set:** 3 transform kinds (translate(dx=1,dy=0), translate(dx=0,dy=1), rotate(90)) × 3 seed colors (1,2,3) = 9 pairs. Each pair: `g_t` single-object 8×8 grid → `g_t1` via `_apply_option_to_grid` with the exact `MacroOption`; waves from the production masked-ramp encoder (`spatial_basis_kind="incommensurate"`, `bg_mask=True`); action wave via `psg.option_waves(g_t, [option])` (production option path). Skipped pair (option absent) → recorded, not fabricated.
- **Training:** `planner.train_transition_step(state, action_wave, next, lr=0.05, valence=1.0)`, K=200 steps, cycling the 9 pairs. Loss history + `loss_ema` recorded every step.
- **Control:** second orchestrator built with identical seed BEFORE training (untrained twin of the treatment).
- **Eval arms (parity with sealed 8.3r):**
  - Arm A = TRAINED transition, canonical 11-axiom boundary, λ_goal=0.0 (production).
  - Arm B = UNTRAINED control, canonical 11-axiom boundary, λ_goal=0.0.
- **Eval transforms:** translation `translate(dx=1, dy=0)`, rotation `rotate(90)`; 8 macro-options (identity + 4 translations + 3 rotations; reflection excluded); full production path: `compile_functor_wave` → `goal_bind` → `options_from_grid`/`option_waves` → `score_actions` → `select_action` (incl. T4 explore gate); decomposition + loop/vmap identity.
- **Eligibility:** `score_eligible=false`, `diagnostic_only=true`, `authorizes_rollout=false` on every return path (single source). NO `game.step` anywhere. Synthetic known-transform pairs are diagnostic-only, NOT ARC demo fabrication.

## Pre-registered gates (NO post-hoc threshold tuning; NO rerun on fire)

- **G0 infra:** canonical boundary load must succeed (fail-closed → `BLOCKED_INFRASTRUCTURE`, no fallback). Decomposition consistency ≤ 1e-4 and loop/vmap identity ≤ 1e-5 (reuse 8.3r guards).
- **G1 (loss floor):** `loss_ema` after K=200 < **0.30**. Secondary (reported, not gating): final raw Sagnac loss ≤ 0.15 (spec target).
- **G2 (ranking, arm A, both transforms):** ladder —
  - `JEPA_ALIGNMENT_PASS`: G1 AND true-EFE rank == 1 for BOTH transforms (spec G4).
  - `JEPA_PARTIAL_SIGNAL`: G1 AND true-EFE rank ≤ 2 for BOTH transforms, AND arm A strictly improves rank vs arm B (control) for at least one transform.
  - `JEPA_TRAINING_INERT`: G1 fails (loss_ema ≥ 0.30) OR no rank improvement vs control (loss descent without ranking change = memorization).
- **G3 (no leakage):** no `game.step` in new source (contract test); eligibility fields always false (contract test).
- **Kill discipline:** any gate fire → verdict verbatim, evidence sealed, NO rollout/eligibility/promotion; same-SHA gate chain required for any promotion.
