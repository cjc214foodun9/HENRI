## Implementation (default-OFF, production path untouched when OFF)
New module `HENRI V2/henri_spatial_carrier_ingress.py`:
- `VectorizedIncommensurateSpatialIngress(dimension=65536, carrier_scale=0.10, device)`.
- Incommensurate band-limited carriers: Omega_x[d] = 2*pi*s*frac(d*tau),
  Theta_y[d] = 2*pi*s*frac(d*sqrt(3)), tau = (sqrt(5)-1)/2. Deterministic buffers.
- CC-OS: `ConnectedComponentSegmenter(background_color=0).segment_grid(grid)` ->
  ObjectRecords (pixels, color, centroid) -> per-object identity codebook
  I_c = e^{j*2*pi*frac(d*sqrt(p_c))} (seeded incommensurate per color).
- O(D) binding: superposed_wave = sum_k I_ck * e^{j(cx_k*Omega + cy_k*Theta)} (complex
  [D/2]) -> concat real/imag -> [D] real -> F.normalize. Fail-closed on empty foreground.
- `.translation_wave(dx, dy)` = e^{j(dx*Omega + dy*Theta)}: exact global phase rotation;
  uniform rigid translation = element-wise complex product (distributes over sum).
- Physics env: `state_to_wave` gains default-OFF `use_carrier_ingress` flag; when ON,
  single object at state-derived centroid (pendulum: (cos theta, sin theta)*scale).

DEVIATION (documented, pre-launch): the blueprint sketch draws Omega_x ~ randn(D)*pi,
which gives E[cos(Omega_d)] ~ 0.007 and FAILS its own gate-1 (>= 0.85) by construction.
This implementation uses band-limited incommensurate carriers with s = 0.10 cycles/px:
E[cos(Omega_d)] = sinc(2*pi*s) ~= 0.937 >= 0.85. Mechanism (incommensurate carriers +
CC-OS masking + O(D) vectorized binding) is implemented as prescribed; only the carrier
BANDWIDTH is corrected to satisfy the stated gate.
